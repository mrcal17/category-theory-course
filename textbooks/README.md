# References - public link registry

The course links to public book pages and author PDFs. No PDFs are committed to
this repository, and the exported notebooks should not contain machine-local
filesystem links. If you want local copies, save them here under the filenames
below; `textbooks/*.pdf` is gitignored.

## Free and legal direct links

- **Leinster.pdf** - Basic Category Theory (Tom Leinster) - the primary text
  https://arxiv.org/abs/1612.09375
- **Riehl.pdf** - Category Theory in Context (Emily Riehl) - the secondary text
  https://math.jhu.edu/~eriehl/context.pdf
- **Hammack.pdf** - Book of Proof, 3e (Richard Hammack) - proof technique, Part 0
  https://www.people.vcu.edu/~rhammack/BookOfProof/
- **Perrone.pdf** - Notes on Category Theory with examples from basic mathematics (Paolo Perrone)
  https://arxiv.org/abs/1912.10642
