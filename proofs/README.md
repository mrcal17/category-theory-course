# Your proofs

Write each proof in `proofs/<module>/pNN_<slug>.md`, using the same filename as its
brief in `exercises/<module>/`. Everything in this folder except this README is
gitignored, so the repository stays solution-free.

A good write-up follows the lecture's proof anatomy:

1. **Goal** - the statement, quantifiers written out.
2. **Given** - the definitions and hypotheses you are allowed to use.
3. **Plan** - one or two sentences on the shape of the argument.
4. **Proof** - every step justified by name.
5. **What made it work** - the idea you would reuse.

Then ask Claude to review it ("review proofs/1a/p03_identities_unique.md"). Review
points at gaps and asks questions; it will not rewrite the proof for you.
